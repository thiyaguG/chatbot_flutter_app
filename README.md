# Digisol Support — mobile app

Flutter client (Android and iOS) for the multi-tenant RAG chatbot backend
(`llama_rag_chatbot`). It is a mobile counterpart of the backend's web widget
(`templates/iframe.html`) and uses the same API.

## Backend API used

| Call | Purpose |
|---|---|
| `POST /api/<tenant>/chat/stream` | One chat turn; the reply is a server-sent event stream (`meta`, `token`, `complete`, `options`, `error`, `done`) |
| `POST /api/<tenant>/reset-conversation` | Discard a conversation's server-side state |
| `GET /api/<tenant>/ui-config` | Title, theme colour, welcome message, feature flags. Optional: the app falls back to built-in defaults |

## Running

```bash
flutter run                                                    # local Flask on the dev machine, from the Android emulator
flutter run --dart-define=API_BASE_URL=http://192.168.1.20:5000  # a phone on the same Wi-Fi
flutter run --dart-define=TENANT_ID=edubot                     # another tenant
```

Debug builds allow plain HTTP; release builds do not yet.

## Layout

- `lib/config` — build-time settings (server address, tenant)
- `lib/api` — event-stream parser, API client, models
- `lib/chat` — controller, local storage, connectivity, screen and widgets
- `test` — unit and widget tests (`flutter test`)
- `assets/branding` — placeholder icon and splash art, generated by
  `tool/make_placeholder_icon.py`
- `web/`, `.claude/launch.json` — browser preview for development only
